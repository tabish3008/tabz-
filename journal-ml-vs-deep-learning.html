Machine Learning vs Deep Learning, Explained Simply

By Tabish Syed • 2 mins read
Scroll

People often use machine learning and deep learning as if they mean the same thing. They are related, but they are not the same.

Machine learning

Machine learning is the broad idea of letting a computer learn patterns from data instead of following rules you wrote by hand. Show it thousands of past house sales and it learns how size and location affect price. Common methods include linear regression, decision trees and random forests.

With classic machine learning, a person usually chooses which features the model looks at, such as the number of rooms or the age of a house. This is called feature engineering.

Deep learning

Deep learning is one kind of machine learning. It uses neural networks with many layers. Each layer learns something a little more complex than the layer before it. In an image model, early layers pick up edges, middle layers pick up shapes, and later layers recognize whole objects like a leaf or a face.

The main difference is that a deep network works out the useful features by itself. You don’t have to describe them.

How to choose

Use classic machine learning when you have a smaller, structured dataset, like a spreadsheet, and you want something fast and easy to explain. Use deep learning when the data is images, audio or text, and you have a lot of it plus the computing power to train on it.

A simple example

Predicting rent from a table of room counts and locations is a good fit for machine learning. Telling a healthy plant leaf from a diseased one using photos is a good fit for deep learning, because a convolutional neural network can learn the visual patterns on its own.

Deep learning is a part of machine learning, and the right choice depends on your data.
