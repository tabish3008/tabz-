Prompt Engineering: Getting Better Answers from AI

By Tabish Syed • 2 mins read
Scroll

The same AI model can give a weak answer to one question and a great answer to another. The difference is usually the prompt. Prompt engineering means writing your request so the model has what it needs to answer well.

1. Be specific

“Write about dogs” leaves the model guessing. “Write a 100-word introduction to dog training for first-time owners” gives it a topic, a length and an audience.

2. Give context

Tell the model who the answer is for and why you need it. Compare “Explain overfitting” with “Explain overfitting to a first-year student who knows basic Python.” The second one gets an answer pitched at the right level.

3. Show an example

If you want a particular format or style, include one short example. Models copy patterns well, so a single sample often works better than a long description.

4. Say what format you want

Ask for a table, a list of five points, or a short paragraph. If the output goes into another program, ask for something it can read, like JSON.

5. Break big tasks into steps

For a hard problem, ask the model to work through it in order, or split it into several smaller prompts. Each step is easier to check, and mistakes are easier to find.

6. Improve it and try again

The first answer is a draft. If it misses, tell the model what to change: “shorter”, “more technical”, “remove the jargon”. Small edits to a prompt often make a big difference.

Prompting is a skill you build by practice. Start with a clear goal, add context, and keep adjusting until the answer is useful.
