Bug-Fixing AI Agent

Personal Project • In progress
Scroll

Overview

A beginner-friendly Python agent that helps fix bugs in a small Python project. It is designed so that a person stays in control of every change.

How it works

  • You give it a description of the bug and the path to your project.
  • It inspects the project files and suggests a fix.
  • It asks for your approval before changing any file.
  • After you approve, it applies the fix and runs the project’s tests.

Design choices

The agent never edits files without asking first, and no API keys are stored in the code. I am building it one small feature at a time, and it is still in progress.

Built with

Python.
